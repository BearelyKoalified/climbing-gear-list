# Climbing & Outdoors Shopping List

A read-only snapshot of my climbing and outdoors gear shopping list (updated November 12, 2026), with picks, prices, sale tags and forum opinions.

The page builds itself on load with a wireframe intro, items and details build in and power down as you open and close them, and it plays two openly licensed synthwave tracks (click INITIALIZE to power up with music):
"Future Travel" by Zodik (CC-BY 3.0) and "Synth Wave by Alex" by Alex McCulloch / Pro Sensory (CC0), both from OpenGameArt.

Live page: https://bearelykoalified.github.io/climbing-gear-list/
